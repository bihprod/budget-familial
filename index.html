Budget Familial
Connectez Supabase pour synchroniser vos données entre vos deux iPhones.
Étape 1
Créer le projet Supabase
Rendez-vous sur supabase.com → Start for free → connectez-vous avec Google.

Cliquez New project → nom : budget-familial → région West EU (Ireland) → Create project.

Attendez environ 1 minute que le projet soit prêt.
Étape 2
Créer les tables (SQL Editor)
Dans votre projet → menu gauche SQL Editor → New query.
Collez le code ci-dessous et cliquez Run :
create table if not exists budget_config ( id text primary key default 'main', budget numeric default 1000, currency text default 'CHF', categories jsonb default '[]' ); create table if not exists budget_months ( month_key text not null, cat_id text not null, amount numeric default 0, comments jsonb default '[]', updated_at timestamptz default now(), primary key (month_key, cat_id) ); alter table budget_config enable row level security; alter table budget_months enable row level security; create policy "allow_all" on budget_config for all to anon using (true) with check (true); create policy "allow_all" on budget_months for all to anon using (true) with check (true);
Étape 3
Vos clés API Supabase
Dans Supabase → Settings ⚙️ (bas à gauche) → API.
Copiez Project URL et anon public key :
